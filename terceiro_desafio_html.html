Introdução

O desenvolvimento web acessível garante que todas as pessoas, incluindo aquelas com deficiências visuais, motoras, auditivas ou cognitivas, possam navegar, compreender e interagir com a Web de maneira autônoma.

"A força da Web está na sua universalidade. O acesso por todas as pessoas, independentemente de deficiência, é um aspecto essencial."
— Tim Berners-Lee, criador da World Wide Web

História e Evolução

A estrutura semântica evoluiu substancialmente com a chegada do HTML5, introduzindo elementos específicos para delimitar regiõess-chave de uma página sem a necessidade excessiva de divisões genéricas.

Acessibilidade e Padrões WAI

A WAI (Web Accessibility Initiative) é uma iniciativa do W3C voltada para criar diretrizes globais (como a WCAG). O uso do texto alternativo via atributo alt em imagens é fundamental para que leitores de tela como o NVDA consigam descrever o conteúdo visual.

Dica de atalho: Você pode utilizar a tecla Tab para navegar entre os links acessíveis e acionar botões usando a tecla Enter.

Clique para ver diretrizes rápidas de acessibilidade
  • Use tags semânticas (como <main>, <header>, <footer>).
  • Forneça contraste adequado entre texto e fundo.
  • Garantir validação de formulários com rótulos claros (<label>).

Recursos Multimídia

O HTML5 introduziu suporte nativo a mídias sem a necessidade de plugins externos através de elementos dedicados como <video> e <audio>, além de legendas temporizadas via <track>.
