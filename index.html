O que é HTML?

O HTML (HTML) é a linguagem de marcação usada para estruturar páginas da web. Com ele dizemos ao navegador o que é um título, um parágrafo, uma lista ou um link.

Ele não é uma linguagem de programação, e sim de marcação. Para dar estilo usamos o CSS e, para dar comportamento, o JavaScript.

Texto em tamanho reduzido, ótimo para observações e notas de rodapé.

Listas

Lista ordenada: passos para criar uma página

  1. Criar um arquivo chamado index.html
  2. Escrever a estrutura básica do HTML
  3. Adicionar títulos, textos e links
  4. Abrir o arquivo no navegador

Lista não ordenada: tags que aprendi

  • Títulos (h1 até h6)
  • Textos (p, strong, i, u, mark, small)
  • Listas (ol, ul, li)
  • Links (a)
  • Outras (hr, sub, sup, blockquote, font, del, abbr)
